プライバシーポリシー

このページは、Windows 用デスクトップアプリ「GCalScheduler（Googleカレンダー予定登録）」（以下「本アプリ」）における、 Google ユーザーデータの取り扱いを説明するものです。

1. 取得する情報

本アプリは、利用者が Google アカウントでログインし許可した場合に限り、次の権限を使用します。

  • https://www.googleapis.com/auth/calendar.events：利用者のカレンダーに予定を作成し、本アプリで登録した予定を取り消す（削除する）ため
  • https://www.googleapis.com/auth/calendar.readonly：登録先として選べるカレンダーの一覧を表示するため

2. 情報の利用目的

取得した情報は、利用者が画面で指示した予定の登録・取り消しと、登録先カレンダーの選択のためだけに使います。 広告、分析、機械学習、その他の目的には使用しません。

3. 情報の保存

  • ログイン情報（アクセストークン）と設定は、利用者のパソコンの %APPDATA%\GCalScheduler フォルダにのみ保存されます。
  • 予定やカレンダーの内容を、開発者や第三者のサーバーに送信・保存することはありません。通信先は Google のサーバーのみです。

4. 第三者への提供

取得した Google ユーザーデータを第三者に販売・提供・共有することはありません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

6. アクセスの取り消しとデータの削除

  • 本アプリの「ログアウト」を押すと、パソコンに保存したログイン情報を削除します。
  • Google アカウントの サードパーティ製のアプリとサービス から、いつでも本アプリへのアクセスを取り消せます。
  • %APPDATA%\GCalScheduler フォルダを削除すると、本アプリが保存したすべてのデータが消去されます。
